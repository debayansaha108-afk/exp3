# Experiment 3 – Adaptive Fragments and Debugging Tasks

## 📌 Description

This experiment is developed as part of the Mobile Application Development Lab using Android Studio. It focuses on implementing Android Fragments, adaptive user interfaces, and debugging techniques.

The experiment provides practical experience in organizing application components, designing layouts, and identifying and resolving errors during Android application development.

## 🚀 Features

- Implements Android Fragment concepts.
- Explores adaptive user interface design.
- Uses XML layouts to design application interfaces.
- Demonstrates Android application development.
- Provides practical experience with debugging techniques.
- Organizes application components into reusable modules.
